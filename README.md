# Assistive Gesture Detection System

## 📌 Overview

The **Assistive Gesture Detection System** is a web-based application that detects and interprets hand gestures in real-time using the webcam. It is designed to assist individuals—especially those with speech or physical impairments—by enabling interaction and communication through simple gestures.

---

## 🚀 Features

* Real-time hand gesture detection in the browser
* No installation required (runs directly in the browser)
* Uses webcam for live input
* Interactive and responsive UI
* Lightweight and fast performance

## 🛠️ Technologies Used

* **HTML** – Structure of the web application
* **CSS** – Styling and layout
* **JavaScript** – Logic and interactivity
* **MediaPipe** – For hand tracking and gesture detection

---

## ⚙️ How It Works

1. The browser accesses the user's webcam
2. Video frames are processed in real time
3. MediaPipe detects hand landmarks (finger positions and joints)
4. JavaScript analyzes the landmarks to identify gestures
5. The detected gesture is displayed or used for interaction

---

## How to Run
- Download or clone the repository
- Open index.html in your browser
- Allow camera access
- Start using gestures

## ▶️ Usage

* Allow camera access when prompted
* Show your hand in front of the webcam
* Perform gestures
* The system will detect and respond accordingly
